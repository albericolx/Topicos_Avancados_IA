# Contexto: Atividade 03 - Loop de Agentes (`artefatos/Atividade_03_LOOP_Agentes/`)

Esta pasta contém o projeto desenvolvido para a atividade prática de simulação de interação entre múltiplos agentes de Inteligência Artificial (cenários de Utopia e Distopia).

## Componentes Principais
- [`multi_agent_sim.py`](multi_agent_sim.py): Script principal que orquestra o loop hierárquico entre agentes remotos (Gemini) e agentes locais (Ollama), com suporte a parâmetros explícitos de temperatura, busca na web (`google_search`) e *Chain-of-Thought* (raciocínio explícito).
- [`logs/`](logs/CONTEXT.md): Transcrições brutas de cada rodada com a contribuição criativa, a crítica sistemática e a síntese coordenadora de cada perfil envolvido no loop.
- [`README.md`](README.md): Guia de execução e documentação técnica do experimento multiagente.
