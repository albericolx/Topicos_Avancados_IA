# Código-fonte dos Modelos de IA (`code/src/`)

Coloque nesta pasta os códigos, scripts de treino e experimentos desenvolvidos para Tópicos Avançados de IA.

### Estrutura Sugerida:
- `models/`: Implementação de grafos, neurônios e camadas.
- `train/`: Loops de treinamento, cálculo de perda e otimizadores.
- `data/`: Datasets sintéticos ou reais utilizados nos testes.
- `plots/`: Scripts de geração de gráficos para o artigo.
